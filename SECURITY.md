# Security policy

KIL will process security-incident traces and exercise enforcement behavior.
Do not commit live credentials, unredacted private indicators, working exploit
payloads, or customer data. Public incident material must be linked to its
source and stored only when redistribution is permitted.

The V3B-1 implementation is a local laboratory harness and research reference,
not a production-supported enforcement component. Treat every KIL release as
research software until a release explicitly states otherwise.
